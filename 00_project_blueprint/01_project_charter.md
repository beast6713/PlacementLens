# Project Charter — PlacementLens

| Item | Definition |
|---|---|
| Project | PlacementLens |
| Type | Student Placement Analytics and Business Intelligence portfolio project |
| Phase-0 owner | Project owner / repository maintainer |
| Duration | Seven implementation days after Phase 0 approval |
| Objective | Turn placement-related student indicators into validated descriptive and comparative insights for students and placement teams. |
| Primary users | Students; placement cell / placement officers |
| Required tools | Python, Pandas, NumPy, Matplotlib, SQL, Power BI, Git/GitHub, Jupyter |
| Success outcome | Reproducible analysis, 15–20 SQL queries, transparent readiness framework, and a validated three-page Power BI dashboard. |

## Project statement

Placement teams often store academic, skills, assessment, experience, and outcome data without a consistent analytical view of placement patterns and preparation gaps. PlacementLens will clean and validate a de-identified, synthetic dataset, analyze observed relationships, and present evidence-backed recommendations.

## Approval authority

The repository maintainer approves CHECKPOINT-00 and any scope change. Analysts may implement only approved requirements and must update the checkpoint and change log at phase completion.
