# Scope and Boundaries

## In scope

- A synthetic, realistic, de-identified student placement dataset.
- Cleaning, validation, Python EDA, SQLite analytics, transparent readiness scoring, Power BI, findings, recommendations, and portfolio documentation.

## Out of scope

- Production applications, APIs, authentication, ERP integration, live tracking, notifications, streaming, cloud/distributed infrastructure, mobile apps, automated recruitment/hiring, deep learning, complex MLOps, and deployment infrastructure.

## Future enhancement backlog

- Public-dataset comparison after license review.
- PostgreSQL migration, cohort/year trends, survey data, or an evaluated prediction model only with separate ethical review and scope approval.

## Scope-control rule

New work must directly support a listed analytical question and fit the seven-day plan. Otherwise add it to the backlog and log the decision.
