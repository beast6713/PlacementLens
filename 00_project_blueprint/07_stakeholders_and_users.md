# Stakeholders and Users

| Stakeholder | Need | Project response | Boundary |
|---|---|---|---|
| Students | Understand preparation patterns and possible gaps. | Readiness components and aggregate benchmarks. | Not a placement guarantee. |
| Placement cell | Target training and examine trends. | Branch, skills, assessment, and experience views. | Not an automated selection tool. |
| Faculty / career teams | Identify curriculum-support opportunities. | Evidence-backed, aggregate recommendations. | Requires contextual review. |
| College management | High-level placement visibility. | Overview metrics and documented limitations. | No real institutional data implied. |
| Analysts / recruiters | Portfolio-quality analytics example. | Reproducible workflow and narrative. | Synthetic data disclosure required. |
