# Analytical Questions

| ID | Question | Core metric / method |
|---|---|---|
| AQ-001 | What is the overall placement rate? | placed / total students |
| AQ-002 | How does placement rate vary by branch? | branch-level rate and count |
| AQ-003 | How does rate vary across CGPA ranges? | approved CGPA bands |
| AQ-004 | How does CGPA differ by outcome? | mean, median, distribution |
| AQ-005 | Is internship experience associated with outcome? | rate by internship count / has internship |
| AQ-006 | Is project experience associated with outcome? | rate by project count / has project |
| AQ-007 | Which skills are most common? | skill adoption rate |
| AQ-008 | Which skills have the highest placement rates? | rate among skill holders, with count |
| AQ-009 | How does coding performance differ by outcome? | score summaries/distribution |
| AQ-010 | How does aptitude performance differ by outcome? | score summaries/distribution |
| AQ-011 | How does communication performance differ by outcome? | score summaries/distribution |
| AQ-012 | What is package distribution? | placed-only package statistics |
| AQ-013 | Which branches have highest mean and median packages? | branch package statistics |
| AQ-014 | What characteristics commonly occur among placed students? | descriptive profile, no causal claim |
| AQ-015 | What are major student skill gaps? | adoption/performance thresholds |
| AQ-016 | Which factors show strongest association? | effect-size/correlation screen with caveats |
| AQ-017 | What recommendations follow from observed evidence? | insight framework |
