# Technology Stack

| Layer | Approved technology | Purpose |
|---|---|---|
| Data generation/analysis | Python 3, Pandas, NumPy | Reproducible synthetic data, cleaning, validation, EDA, readiness. |
| Visualization in notebooks | Matplotlib | Transparent analysis plots. |
| Optional statistical support | SciPy | Tests/intervals only where assumptions are documented. |
| Database | SQLite | Portable local SQL analytics for the seven-day scope. |
| BI | Power BI Desktop / DAX | Three-page interactive dashboard. |
| Documentation | Markdown, Jupyter | Phase records, methods, narrative. |
| Version control | Git/GitHub | Change history and portfolio publishing. |

Scikit-learn, PostgreSQL, and any application framework are not required for the initial scope. Adding them requires a change-log entry and approval.
