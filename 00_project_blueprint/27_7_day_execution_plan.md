| 1 | 1 — Data Foundation | Freeze generator assumptions; generate/profile raw CSV; finalize source note and actual row count. | 01 |

| 4 | 3 — SQL Analytics | Create SQLite schema/load; implement 15–20 queries; reconcile core metrics. | 03 |
| 5 | 4 — Insights + Readiness | Calculate PRI/gaps; publish 5–8 evidence-backed findings, limitations, recommendations. | 04 |
| 6 | 5 — Power BI | Build overview, skills/performance, and readiness pages; document DAX. | partial 05 |
| 7 | 5 — Finalization | Reconcile dashboard; polish README/docs/screenshots/interview narrative; reproducibility QA. | 05 |

If time becomes constrained, preserve data validation, core AQ coverage, SQL reconciliation, PRI transparency, and dashboard reconciliation. Defer enhancements rather than weaken validation.
