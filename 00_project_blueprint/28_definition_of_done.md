# Definition of Done

PlacementLens is complete only when all of the following are checked at CHECKPOINT-05:

- [ ] Problem, requirements, scope, and ethics documentation complete.
- [ ] Synthetic dataset source and schema are documented.
- [ ] Data dictionary and quality rules are implemented and passed.
- [ ] Clean dataset and reconciliation report are produced.
- [ ] Python EDA and statistical/association analysis are reproducible.
- [ ] SQLite database and 15–20 meaningful SQL queries are complete and cross-checked.
- [ ] 5–8 evidence-backed findings and limitations are published.
- [ ] PRI and student-gap analysis are reproducible and transparently framed.
- [ ] Recommendations are tied to actual findings.
- [ ] Three-page Power BI dashboard is complete and reconciled.
- [ ] README, portfolio narrative, screenshots, and interview explanation are complete.
- [ ] Repository is organized; checkpoints/change log are current; a clean rerun is verified.
- [ ] Final checkpoint is PASS and approved.
