# Web Application Audit — PlacementLens Dashboard (`dashboard/`)

## 1. Web Application Summary
- **Technology Stack:** React + Vite + Tailwind CSS + Framer Motion + Recharts + Lucide Icons + Magic UI.
- **Port / Location:** Running on `http://localhost:5173/` inside `dashboard/`.
- **Build Status:** **PASS** (Zero build or JSX syntax errors).

## 2. Component Inventory
- `App.jsx`: App shell, left sidebar navigation, top bar global slicers, filter reset button.
- `BorderBeam.jsx`: Rotating glowing border beam for hero cards.
- `NumberTicker.jsx`: Animated numerical counting tickers.
- `BentoGrid.jsx`: Bento grid layout container and cards.
- `ParticlesBackground.jsx`: Interactive canvas particle grid background.
- `MagicMarquee.jsx`: Scrolling ticker ribbon for findings.
- `ShimmerButton.jsx`: Glowing CTA filter reset button.

## 3. Data Integration Audit
- Consumes JSON dataset `dashboard/src/data/placementData.json` generated by `scripts/export_dashboard_data.py`.
- 100% data fidelity with `placementlens_students_clean.csv`.
- Zero mock production values or fake student counts.
